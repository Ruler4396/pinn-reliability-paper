# 实验设计草案

## 目标

本文实验不只是为了证明某个 PINN 在某个案例上有效，而是为了回答以下问题：

1. 在稀疏与噪声观测下，PINNs 的可靠边界如何变化
2. 多维可靠性指标是否比单一误差提供更多信息
3. 不同 PDE 系统中的失效路径是否一致
4. 可靠性分区能否反过来指导训练策略

## 案例栈

主案例共三类：

1. Poisson / 稳态扩散
2. 稳态 Stokes / Poiseuille 微流动
3. 黏性 Burgers 方程

## 共享实验变量

所有案例尽量共享以下变量定义：

- 稀疏度 `s`
- 噪声强度 `sigma`
- 随机种子集合
- 模型容量等级
- 训练预算等级
- 可靠区 / 临界区 / 不可靠区阈值

## 推荐参数网格

### 稀疏度

建议主网格：

- `1%`
- `5%`
- `10%`
- `15%`

理由：

- `1%` 用于观察极端稀疏条件
- `5%` 对应现有微流动仓库中已沉淀的数据条件
- `10%` 和 `15%` 用于观察边界回升趋势

### 噪声强度

建议主网格：

- `0%`
- `1%`
- `3%`
- `5%`

理由：

- `0%` 提供理想观测基线
- `1%` 对应轻微扰动
- `3%` 对应现有仓库中的已沉淀主设定
- `5%` 用于观察明显退化

### 随机种子

建议：

- pilot 阶段：`1` 个种子
- 正式相图阶段：`3` 个种子

## 指标结构

### 通用维度

1. 物理一致性
2. 训练稳定性
3. 数值精度
4. 结构稳定性

### 案例实例化

#### Poisson / 扩散

- 物理一致性：PDE 残差、边界条件残差
- 训练稳定性：损失波动、停滞比例
- 数值精度：相对 L2、R2
- 结构稳定性：剖面相似度、极值个数偏差、梯度平滑度

#### Stokes / 微流动

- 物理一致性：散度、动量残差、压力梯度一致性
- 训练稳定性：损失波动、停滞比例
- 数值精度：速度相对 L2、压力相对 L2、R2
- 结构稳定性：中心线速度偏移、剖面相似度、壁面剪切误差

#### Burgers

- 物理一致性：方程残差
- 训练稳定性：损失波动、停滞比例
- 数值精度：相对 L2、R2
- 结构稳定性：高梯度区域位置偏移、剖面相似度、梯度分布偏差

## 实验分组

### E1. 单案例相空间扫描

每个案例分别扫描：

- `s in {1,5,10,15}%`
- `sigma in {0,1,3,5}%`

输出：

- 综合可靠性热图
- 四维得分热图
- 代表性工况可视化

### E2. 多维指标有效性验证

目的：

- 检查是否存在“一坏全坏 / 一好全好”
- 验证多维框架是否提供比单一误差更多的信息

输出：

- 各维度相关性矩阵
- `R` 与单一误差指标的关系图
- 不同维度的失效先后顺序分析

### E3. 跨案例比较

目的：

- 比较不同 PDE 的可靠边界形状
- 比较不同 PDE 中首先退化的维度

输出：

- 跨案例边界对比图
- 维度主导失效类型统计

### E4. 区域感知训练

目的：

- 检验由可靠性分区指导的训练策略是否在临界区有效

选择：

- 每个案例优先挑选 `1-2` 个临界工况

比较：

- baseline PINN
- region-aware PINN

## 试运行策略

当前仓库已具备可直接运行的稳态微流动代码，因此建议先做一个最小试运行：

- 案例：Stokes / contraction 微流动
- 训练源：`obs_sparse_5pct_noise_3pct`
- 训练案例：`C-base`
- 验证案例：`C-val`
- 降低 epoch 和网络宽度，先测通路与耗时

## 基线优先原则

在引入噪声之前，必须先确认最简单 PINN 在对应案例上已经学到了一个足够可信的无噪基线。否则后续看到的退化既可能来自数据退化，也可能只是来自模型本身尚未收敛。

因此每个案例都按以下顺序推进：

1. `clean baseline`
   目标：在无噪、较充分观测条件下获得一个可接受的基本解。

2. `sparse clean`
   目标：仅考察观测稀疏带来的退化，不混入噪声因素。

3. `sparse noisy`
   目标：在确认前两步成立后，再研究噪声与稀疏的耦合影响。

推荐执行顺序：

- 先从 `Poisson` 开始建立最小闭环
- 再扩展到 `Burgers`
- 最后进入 `Stokes / Poiseuille`

这样可以避免一上来就在最复杂案例上混杂多个因素，导致结论难以解释。

## 正式实验前需要回答的问题

1. Poisson 和 Burgers 是否在同一代码框架里实现，还是先用独立最小实现
2. 结构稳定性指标的阈值是否统一采用预实验确定
3. 区域感知训练是统一策略还是按案例微调
4. pilot 结果是否支持扩大到完整相图扫描
