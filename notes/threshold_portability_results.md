# 跨变体阈值/校准可移植性分析

本轮分析基于现有的跨 PINN 变体稳健性结果完成，没有新增训练。分析脚本为：

- `minimal_pinn/analyze_threshold_portability.py`

输出目录：

- `minimal_pinn/results/analysis/threshold_portability_v1`

核心输出文件：

- `threshold_reference.csv`
- `point_portability_summary.csv`
- `label_disagreement_summary.csv`
- `case_rule_portability_summary.csv`
- `severity_ordering_summary.csv`
- `threshold_portability_summary.json`
- `figure_23_rule_portability_spans.png`
- `figure_24_severity_ordering.png`

## 1. 分析目的

本轮分析直接回答两个问题：

1. 由当前最小 PINN 基线得到的固定 `rel_l2` 边界阈值，能否跨 PINN 变体保持一致语义？
2. 由当前案例内重标定得到的综合可靠性 `R`，在跨 PINN 变体时还能否保持可解释的严重度排序？

为此我们比较了三类规则：

- 固定绝对 `rel_l2` 阈值：直接复用当前案例基线阈值。
- 变体内相对 `rel_l2` 阈值：用“安全点均值 × 基线相对系数”得到每个变体自己的阈值。
- 固定 `R` 分区：`R >= 0.9` 记为 reliable，`0.7 <= R < 0.9` 记为 critical，`R < 0.7` 记为 unreliable。

## 2. 主要结果

### 2.1 固定绝对 `rel_l2` 阈值不具备跨变体可移植性

这个结论最明确。

- `Stokes-Poiseuille` 中，`critical_obs8_noise0125` 的越界率从 baseline 的 `0.667` 变成 `capacity_v1` 和 `weight_balanced_v2` 的 `0.0`。
- 同一案例的 `failure_obs8_noise0175` 也从 `1.0` 下降到 `0.333`。
- `Burgers` 中，`transition_obs48_noise010` 的越界率在不同变体下从 `0.0` 到 `1.0` 全部出现。

这说明“边界是否跨过”会明显随 PINN 配方变化。当前固定 `rel_l2` 阈值只能在“同一训练配方内部”解释边界，不能当成跨变体的统一标准。

### 2.2 安全点归一化后的相对 `rel_l2` 阈值只能部分修正问题

我们用每个案例在 baseline 下的“阈值 / 安全点均值”作为相对系数，再把这个系数映射到其他变体的安全点均值上。

这一步确实解决了一部分问题：

- `Burgers safe_obs64_noise005` 在固定绝对阈值下存在变体间分歧，但相对阈值下三种变体都回到同样的越界率 `0.333`。

但它不是通用修复：

- `Stokes-Poiseuille critical_obs8_noise0125` 在相对阈值下反而出现更大的跨变体分歧，`mean_relative_cross_span = 0.667`，且最坏标签跨度达到 `1.0`。
- `Burgers seed_sensitive_obs32_noise010` 在固定阈值下一致越界，但在相对阈值下出现 `1.0 -> 0.333 -> 1.0` 的分裂。

因此，相对阈值不能作为最终解决方案。它只能说明一部分阈值漂移确实来自“安全误差基线不同”，但并不能完全吸收由训练配方带来的边界变化。

### 2.3 固定 `R` 分区更适合作为严重度排序工具，而不是通用硬阈值

从固定 `R` 分区的“标签一致性”看，它并不总是优于 `rel_l2` 阈值：

- `Poisson` 的 `R` 主类别在跨变体下全部发生分歧。
- `Burgers` 的四个代表点在 `R` 主类别上全部出现分歧。

这说明 `R >= 0.9 / 0.7` 这组固定切分，也不能被写成完全跨变体可复用的硬阈值。

但从“严重度排序”看，`R` 仍然有价值。

- `Stokes-Poiseuille` 中，三种变体下 `severity -> -R` 的 Spearman 相关都保持在 `1.0`。
- `Burgers` 的 `weight_balanced_v2` 中，`severity -> rel_l2` 的相关下降到 `0.6`，而 `severity -> -R` 仍有 `0.8`。

这说明：

- 固定 `R` 分区并不适合作为跨变体硬阈值。
- 但 `R` 作为排序或相对严重度指标，仍然比单一 `rel_l2` 更稳。

### 2.4 当前最稳的跨变体结论是“排序可迁移，绝对阈值不可迁移”

综合三类规则后，当前最稳的结论是：

- `Poisson / Stokes-Poiseuille / Burgers` 的角色分工仍然存在。
- 不同变体会显著移动绝对边界位置。
- 固定绝对阈值和固定 `R` 分区都不应直接外推成跨变体工程标准。
- 更可靠的可迁移信息是：
  - 边界的大致形态
  - 相对严重度排序
  - 主导失效机制

## 3. 对论文主张的影响

这轮结果要求论文继续收紧两个地方。

第一，不能把当前的 `rel_l2` 边界阈值写成通用规则。  
更准确的表述应为：

- 当前阈值在“案例内、训练配方内”有用
- 跨变体时必须重新校准

第二，不能把 `R = 0.9 / 0.7` 直接写成普适分区标准。  
更准确的表述应为：

- 这组切分目前是研究阶段的统一展示口径
- `R` 的主要价值在于严重度排序和多维结构解释
- 跨变体部署时仍需重新做配方相关校准

## 4. 现在已经回答了什么，仍未回答什么

### 已回答

- 绝对边界位置显著依赖 PINN 配方。
- 安全点归一化只能部分缓解阈值漂移。
- `R` 的排序信息比单一 `rel_l2` 更稳。

### 尚未完全回答

- 能否构造一个真正跨变体稳定的、无量纲化边界量？
- `R` 的切分阈值是否能通过少量校准点迁移到新变体？
- 更强或更复杂的 PINN 家族下，这个结论是否仍保持？

## 5. 下一步建议

最合理的后续不是继续扩更多点，而是做下面两项之一：

1. 设计“小样本迁移校准”实验  
   只用每个新变体的少数安全/失效点，重新映射 `R` 或 `rel_l2` 阈值，检查是否能恢复一致语义。

2. 设计“无量纲边界量”实验  
   尝试用“相对安全误差倍数 + 多维分数变化量”的组合替代单一绝对阈值。

当前结论已经足够支持论文写成：

- 多维可靠性结构和严重度排序具有方法学价值
- 但绝对边界阈值不具备直接跨变体可移植性
