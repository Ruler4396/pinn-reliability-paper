# 下一阶段实验设计：单维 vs 多维统计检验 + 跨 PINN 变体稳健性实验

本文档给出下一阶段的完整实验设计，目标是回答两个核心问题：

1. 多维失效是否真的存在，还是单一潜变量的不同映射？
2. 当前结论是否依赖于我们这套最小 PINN 的具体实现？

---

## 一、总目标与产出

### 1.1 总目标

通过一套低成本但可辩护的后续实验，验证以下两点：

1. `Poisson / Stokes-Poiseuille / Burgers` 三类系统的“维度强度分层”是否成立。
2. 该分层以及 `Burgers` 的概率边界/训练干预结果，是否能在少量 PINN 变体下保持稳定。

### 1.2 目标产出

后续阶段完成后，至少应新增以下产物：

1. 一份“单维 vs 多维”统计分析结果
2. 一份“跨 PINN 变体稳健性”结果
3. 2 到 3 张核心图
4. 一段可以直接写入论文讨论与局限性的正文

---

## 二、实验 A：单维 vs 多维统计检验

这一部分尽量基于现有结果完成，不再大量新增训练成本。

### 2.1 研究问题

我们要检验的不是“有没有四个指标”，而是：

`高风险工况的变化是否基本能被一个潜在失效轴解释，还是至少需要两个以上相对独立的维度。`

### 2.2 数据来源

直接使用当前已完成的矩阵结果：

- `Poisson` 粗矩阵
- `Stokes-Poiseuille` 粗矩阵 + 边界细化矩阵
- `Burgers` 粗矩阵 + 边界细化矩阵 + 局部多 seed 概率边界矩阵

使用的指标：

- `physics_consistency_recal`
- `training_stability_recal`
- `numerical_accuracy_recal`
- `structural_stability_recal`
- `rel_l2`
- `reliability_raw_recal`

### 2.3 分析任务

#### A1. 相关矩阵与层次聚类

对每个案例分别计算：

- 四个维度之间的 Pearson/Spearman 相关矩阵
- 四个维度与 `rel_l2`、`R` 的相关矩阵

目标：
- 看四个维度是否近乎完全共线
- 看 `Burgers` 是否明显比 `Poisson` 更不共线

判据：
- 若所有维度相关系数在所有案例中都接近 `|0.95|` 以上，则多维性很弱
- 若 `Burgers` 中出现明显低于这一水平的配对，则支持多维性

#### A2. 主成分解释率（PCA）

对每个案例在标准化后的四维得分上做 PCA，记录：

- 第一主成分解释率 `PC1`
- 前两主成分累计解释率 `PC1+PC2`

目标：
- 检验高风险工况是否基本落在单轴上

判据：
- 若 `Poisson` 的 `PC1` 很高，例如 `>0.85`，说明近似一维
- 若 `Burgers` 的 `PC1` 明显较低，且需要 `PC1+PC2` 才能解释大部分方差，说明多维性更强

#### A3. 高风险区的一维可分性检验

方法：

1. 以当前重标定后的 `R` 或边界阈值定义高风险工况
2. 使用仅 `rel_l2` 的一维排序与使用四维得分的二维/四维表示分别做分类
3. 比较它们区分：
   - 安全区
   - 过渡区
   - 失效区

建议使用：
- logistic regression（1D）
- logistic regression（4D）

目标：
- 看四维表示是否在 `Burgers` 上明显优于单维表示

判据：
- 若 `Burgers` 上 4D 分类明显优于 1D，而 `Poisson` 上差异很小，则最符合当前主线

#### A4. 条件独立/残差分析

核心问题：

`training_stability` 和 `structural_stability` 是否只是 `rel_l2` 的单调函数？

做法：

1. 用 `rel_l2` 回归预测 `training_stability_recal` 和 `structural_stability_recal`
2. 检查残差是否仍与高风险工况、概率边界位置显著相关

目标：
- 判断这些维度是否提供了超出单一误差的信息

判据：
- 若 `Burgers` 中残差仍能区分风险状态，则说明不是简单映射

### 2.4 预期最优结果

最希望看到的模式是：

- `Poisson`：高相关、高 `PC1`，近似一维
- `Stokes-Poiseuille`：中等相关，弱多维
- `Burgers`：较低相关、`PC1` 不足、4D 判别优于 1D

### 2.5 若结果不理想怎么处理

若发现：
- `Burgers` 也几乎完全一维

则需要下调 claim，改写为：

`本文提出了一套用于检验失效是否具有多维性的框架；在当前最小 PINN 基线上，复杂系统虽然表现出概率边界与训练不稳定窗口，但其大部分方差仍可由单一退化轴解释。`

## 三、实验 B：跨 PINN 变体稳健性实验

这一部分的目标不是追求 SOTA，而是排除“单个实现 artifact”风险。

### 3.1 研究问题

我们需要回答：

`当前观察到的角色分工、概率边界和训练干预现象，是 PDE 自身更稳定的性质，还是这一个最小 PINN 配方的偶然产物？`

### 3.2 变体设计原则

考虑到算力有限，变体数量控制在 `3` 个以内，并且每个变体只做小范围验证。

建议使用以下三类 PINN 变体：

#### V0. Baseline

- 当前最小 PINN
- `tanh`
- `64 x 64 x 64`
- 当前默认 loss 权重

作用：
- 作为当前主结果基线

#### V1. Higher-capacity variant

- `tanh`
- `96 x 96 x 96`
- 其余设置保持不变

作用：
- 检查容量提升是否只会平移边界，还是会改变边界形态与维度主导模式

#### V2. Weight-balanced variant

- 网络结构保持 baseline
- 调整训练权重，例如弱化数据项、增强 physics/boundary 的平衡
- 或保持权重不变但引入简单学习率衰减

作用：
- 检查结论是否对训练配方过于敏感

说明：
- 不建议在这一阶段引入完全不同的 PINN 家族，否则实现成本过高、变量过多
- 目标是“最小成本的稳健性检查”，不是全面 benchmark

### 3.3 评估工况选择

不要对整个矩阵重跑。只选最有信息量的代表点。

#### Poisson

选 2 个点：
- 一个安全点
- 一个高退化但未失效点

建议：
- `obs=256, noise=0.0`
- `obs=8, noise=0.20`

作用：
- 检查它是否仍然是稳健对照

#### Stokes-Poiseuille

选 3 个点：
- 一个安全点
- 一个临界点
- 一个失效点

建议：
- `obs=64, noise=0.0`
- `obs=8, noise=0.125`
- `obs=8, noise=0.175` 或 `0.20`

作用：
- 检查规则边界和数值误差主导是否稳定

#### Burgers

选 4 个点：
- 一个安全点
- 一个过渡点
- 一个种子敏感点
- 一个稳定失效点

建议：
- `obs=64, noise=0.05`
- `obs=48, noise=0.10`
- `obs=32, noise=0.10`
- `obs=32, noise=0.175`

作用：
- 检查概率边界和多维主导模式是否稳定

### 3.4 随机种子设置

每个变体每个工况建议使用：

- `3` 个 seed

原因：
- 当前机器资源有限
- 这是最小可用统计量

### 3.5 重点评估指标

每个工况记录：

- `rel_l2`
- `R`
- 四个维度得分
- 边界是否越界
- 跨 seed 标准差

### 3.6 需要回答的核心问题

#### B1. 角色分工是否稳定

检查：

- `Poisson` 是否仍然最稳
- `Stokes-Poiseuille` 是否仍然表现为规则边界
- `Burgers` 是否仍然最容易出现高方差过渡区

#### B2. 概率边界是否稳定

检查：

- 在 `Burgers` 过渡区，越界率是否仍呈现中间值，而不是所有变体都变成全好或全坏

#### B3. 维度主导模式是否稳定

检查：

- `Stokes-Poiseuille` 是否仍偏数值误差主导
- `Burgers` 是否仍比其他系统更强调 training/structure

#### B4. `dim-guided v2` 的正结果是否稳定

只在 `Burgers` 临界工况上做：

- baseline vs naive v1 vs dim-guided v2

检查：
- `dim-guided v2` 是否在变体下仍能优于 naive v1

### 3.7 判据

如果出现以下模式，则可以显著增强论文说服力：

1. 不同变体下绝对边界位置会移动，但角色分工保持稳定
2. `Burgers` 的概率边界仍存在
3. `Burgers` 的多维主导模式仍强于 `Poisson` 和 `Stokes`
4. `dim-guided v2` 在 `Burgers` 上至少对大多数变体仍优于 naive v1

若结果不稳定，则论文应改成：

`当前结论适用于最小 PINN 族中的一类实现，而非所有 PINN。`

## 四、执行顺序

### Phase 1：零新增训练成本分析

先做：
- 相关矩阵
- PCA
- 一维 vs 四维可分性
- 条件残差分析

这是最低成本、最高信息密度的一步。

### Phase 2：最小稳健性验证

再做：
- `V1` higher-capacity
- `V2` weight-balanced
- 只在选定代表点上跑

### Phase 3：训练干预稳健性

最后做：
- `Burgers` 临界工况上的三策略对比
- 看 `dim-guided v2` 是否跨变体仍成立

## 五、最终要写进论文的结论模板

如果结果按预期成立，论文里可以写成：

1. `Poisson`、`Stokes-Poiseuille` 与 `Burgers` 在维度强度上呈现稳定分层。
2. 简单系统的退化近似可由单一主轴解释，而复杂系统特别是 `Burgers` 需要多个维度联合解释。
3. 这种分层在少量 PINN 变体下保持稳定，说明当前主线并非单个实现的偶然产物。
4. 训练干预的有效性仍具有系统依赖性，但 `Burgers` 上的正结果表明主导失效维度可以转化为有意义的设计线索。

如果结果不完全成立，则需退一步写成：

1. 多维框架的主要价值在于检验失效是否真的多维。
2. 在当前最小 PINN 基线上，`Burgers` 表现出最明显的多维与概率边界现象。
3. 其他系统更接近单轴退化。
