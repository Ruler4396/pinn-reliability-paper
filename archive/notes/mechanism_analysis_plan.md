# PINN 退化机制分析计划

## 目标

从第一原理出发，回答核心问题：**在稀疏和噪声观测下，PINN 沿什么方向退化？退化的形态由什么决定？**

---

## 一、当前已有成果

### 1.1 六个成功案例的收敛状态

| 案例 | clean rel_l2 | 最后 20 epoch loss 下降 | 收敛状态 | 退化信号强度 |
|------|:---:|:---:|------|------|
| Stokes | 0.010 | -8.2% | 接近收敛 | 强（3.9×） |
| Fisher-KPP | 0.013 | -5.3% | 接近收敛 | 强（5.6×） |
| Allen-Cahn | 0.008 | -9.1% | 仍在下降但慢 | 强（12×） |
| Burgers | 0.018 | **-24.7%** | 明显未收敛 | 强（5.4×） |
| Poisson | 0.097 | -4.4% | 未收敛 | 无（不退化） |
| 热方程 | 0.016 | ~振荡 | 未收敛 | 中等（6.7×） |

### 1.2 三个已识别的退化原型

| 原型 | 零空间维度 | 边界形态 | 机制 | 代表案例 |
|------|:---:|------|------|------|
| A: 不退化 | 0 | 无边界 | 椭圆正定性压制所有扰动 | Poisson |
| B: 窄而单调 | 1 | 确定性边界 | 单零模 + 高曲率 + 均匀信息 | Stokes, Allen-Cahn |
| C: 宽概率带 | 3+ | 概率边界 | 多零模 + 对流耦合 + 多谷优化 | Burgers |

### 1.3 四因素退化决定模型

```
退化方向     ← PDE 损失的近似零空间维度
过渡带陡度   ← 零空间方向上的损失曲率
种子方差     ← 优化景观的多谷性
退化规则性   ← 信息密度的时空均匀性
```

控制对照对：

| 因素 | 对照对 | 分离出的效应 |
|------|------|------------|
| 零空间维度 | Poisson vs Stokes | 0 维 → 不退化；1 维 → 窄边界 |
| 损失曲率 | Stokes vs Fisher-KPP | 高曲率 → 窄过渡；中曲率 → 宽过渡 |
| 空间耦合性 | Allen-Cahn vs Burgers | 反应非线性 → 不多谷；对流非线性 → 多谷 |
| 信息均匀性 | Stokes vs 热扩散 | 均匀 → 单调退化；不均匀 → 斑块退化 |

### 1.4 失败案例

| 案例 | clean rel_l2 | 失败原因 | 处理 |
|------|:---:|------|------|
| 波方程 | 0.215 | 二阶时间导数，tanh 网络病态 | 放弃 |
| Taylor-Green | 0.445 | ν=0.01 太小，高 Re 流动 | 暂放，需调参 |
| Gaussian pulse | 0.201 | 窄峰+大域，tanh 不友好 | 暂放，需改问题设定 |
| Bimodal | 0.093 | case 文件丢失 | 暂放 |

## 二、关键缺口

| 缺口 | 严重性 | 说明 |
|------|:---:|------|
| 零空间维度 > 1 只有 Burgers 一个案例 | **高** | 无法区分"宽边界来自多零模"还是"Burgers 特有性质" |
| Burgers 基线未充分收敛 | 中 | loss 在 500 epoch 仍下降 24.7% |
| 参数敏感性未验证 | 中 | 配点数、训练轮数、损失权重的影响未检验 |

## 三、行动计划

### Phase 1：收敛验证（优先级最高）

**目标**：确认 500 epoch 的训练预算是否足以支撑退化研究的结论。

**操作**：
1. 对 Burgers 跑 1500 epoch 的 clean baseline（3-5 seeds）
2. 对 Allen-Cahn 跑 1500 epoch 的 clean baseline（3-5 seeds）
3. 比较 500 vs 1500 epoch 下的：
   - clean baseline rel_l2
   - 退化模式（选取 2-3 个代表点，比较 rel_l2 在不同 obs/noise 下的变化趋势）
   - 多种子方差

**验收标准**：
- 如果 1500 epoch 的退化模式与 500 epoch 一致（排序不变，趋势不变）→ 现有结论可靠
- 如果退化模式显著改变 → 需要将主实验的训练预算提高到 1500 epoch

**预期结果**：
- Burgers：rel_l2 可能从 0.018 降到 0.010-0.012，但退化模式（宽概率带）应保持
- Allen-Cahn：rel_l2 可能从 0.008 降到 0.005-0.006，退化模式应保持

### Phase 2：零空间维度 > 1 的第二个案例

**目标**：检验"多零模 → 宽边界"假说。

**方案**：Allen-Cahn 圆形界面

| 属性 | 值 |
|------|------|
| PDE | $-\varepsilon^2\Delta u - u + u^3 = 0$（与现有 Allen-Cahn 完全相同） |
| 真解 | $u = \tanh\left(\frac{R - \sqrt{(x-x_0)^2+(y-y_0)^2}}{\sqrt{2}\varepsilon}\right)$ |
| 参数 | $\varepsilon=0.1$, $R=0.3$, $(x_0,y_0)=(0.5,0.5)$ |
| 零空间维度 | 2（圆心位置 $(x_0, y_0)$） |
| 域 | $[0,1]^2$ |
| 实现改动 | 修改 `allen_cahn.py` 的 `truth()` 和 `structure_error()` |

**实验流程**：
1. 实现圆形界面的 Allen-Cahn case
2. 跑 clean baseline（obs=256, noise=0, 5 seeds），确认 rel_l2 < 0.02
3. 跑粗矩阵（6 obs × 5 noise = 30 runs, 单种子）
4. 如果观察到退化 → 跑概率矩阵（4 obs × 5 noise × 5 seeds）
5. 与直线界面 Allen-Cahn 和 Burgers 对比

**两种可能结果及其含义**：

| 结果 | 含义 |
|------|------|
| 圆形 Allen-Cahn 表现出宽边界（类似 Burgers） | 确认"多零模 → 宽边界"是跨机制的普遍规律 |
| 圆形 Allen-Cahn 表现出窄边界（类似直线 Allen-Cahn） | 多零模本身不够，还需要非线性对流耦合 |

**注意**：需要验证圆形界面在有限域上是否真的有 2 个零模。如果边界条件约束了圆心位置，零空间维度可能降回 1。可以通过检查不同种子的圆心位置是否漂移来验证。

### Phase 3：参数敏感性验证

**目标**：确认结论不依赖于特定的参数选择。

**最小验证集**（以 Burgers 为测试案例）：

| 实验 | 对比 | 代表点 | 种子数 |
|------|------|--------|:---:|
| 配点数 | 2048 vs 4096 | 2-3 个临界点 | 3 |
| 训练轮数 | 500 vs 1000 | 同上 | 3 |
| 损失权重 | (10,1,10) vs (1,10,1) | 同上 | 3 |

**验收标准**：
- 如果参数变化后，退化模式（宽概率带、多维主导）保持 → 结论稳健
- 如果退化模式消失 → 需要在论文中显式声明参数依赖性

## 四、关于协议设计的决策

### 4.1 统一 vs 分开

**决策**：保持 500 epoch 统一协议作为主实验，增加"协议充分性验证"层。

**理由**：
- 统一协议是论文的核心卖点之一——"在完全相同的条件下比较不同 PDE"
- 分开协议会引入混淆变量，破坏可比性
- 验证层可以证明"即使给更多预算，结论也不会改变"

### 4.2 是否放弃失败案例

**决策**：
- 波方程：**放弃**（结构性问题，不是调参能解决的）
- Taylor-Green：**暂放**（如需要，调参到 ν=1.0 重新验证）
- Gaussian pulse：**暂放**（如需要，改问题设定）
- Bimodal：**暂放**（需恢复 case 文件）

### 4.3 现有六个案例是否足够

**决策**：足够支撑当前的机制框架。

**理由**：
- 三种退化原型各有至少一个代表
- 四个控制对照对覆盖了四个关键因素
- 零空间维度 > 1 的跨机制检验通过 Phase 2 补充

## 五、预期产出

完成以上三个 Phase 后，论文的机制解释部分将有以下支撑：

| 机制主张 | 支撑证据 |
|---------|---------|
| 零空间维度决定退化方向数 | 6 个案例（维度 0/1/2/3+） |
| 多零模 → 宽边界 | Burgers + 圆形 Allen-Cahn（2 个独立案例） |
| 损失曲率决定过渡陡度 | Stokes vs Fisher-KPP 对照 |
| 信息均匀性决定退化规则性 | Stokes vs 热扩散 对照 |
| 非线性类型影响多谷性 | Allen-Cahn（反应）vs Burgers（对流）对照 |
| 结论不依赖于训练预算 | 500 vs 1500 epoch 验证 |
| 结论不依赖于参数选择 | 配点数/权重敏感性验证 |
