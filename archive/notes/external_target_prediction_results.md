# 单维 vs 多维预测外生标签

本实验不再使用由多维框架自身定义的内部标签，而是转向多 seed 结果给出的外生标签：

- `high_failure`：某工况在多 seed 下的越界率 `cross_rate >= 0.5`。
- `seed_sensitive`：某工况的越界率满足 `0 < cross_rate < 1`。

对比使用同一 LOOCV 最近质心分类器，仅改变输入表示：

- `rel_l2 only`：单一误差基线。
- `R only`：四维框架聚合后的单标量。
- `4D state`：四个重标定维度组成的状态向量。

## Pooled 结果

- 在 `high_failure` 任务上，`rel_l2 only`、`R only` 与 `4D state` 的准确率分别为 `0.513`、`0.692` 与 `0.667`；对应 balanced accuracy 分别为 `0.518`、`0.688` 与 `0.662`。
- 相比单一 `rel_l2`，`R only` 的准确率提升约 `0.179`，`4D state` 提升约 `0.154`。 但精确 McNemar 检验尚未达到显著：`rel_l2 -> R` 的 `p=0.281`，`rel_l2 -> 4D` 的 `p=0.377`。
- 在 `seed_sensitive` 任务上，`rel_l2 only` 的 balanced accuracy 为 `0.786`，高于 `R only` 与 `4D state` 的 `0.641`。 这说明多维框架当前更擅长预测“会不会跨 seed 大概率失效”，但还不足以替代专门的概率边界分析去识别“种子敏感而非必然失效”的中间态。

## 解释

- 这组结果补上了 `H2` 中最容易被质疑的一环：多维框架不只是更会解释自己的内部评分，它对跨 seed 的外生失败标签也更接近有效。
- 但证据强度仍应写成“中等或初步支持”，不能写成“统计上已完全确证”。当前样本量只有 `39` 个点级样本，配对精确检验仍偏宽。
- 更稳的表述应是：多维框架在 `high_failure` 这类外生失败风险标签上优于单一 `rel_l2`，而对 `seed_sensitive` 这类更细粒度的边界宽度标签，仍需要概率边界与多 seed 专项分析共同支撑。
