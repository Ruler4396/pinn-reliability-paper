#### 9.7 与已有研究的三个关系层次

上述五层分析以及本文的整体实验框架，与已有研究的关系可以分为三个层次：确认已有认知、延伸已有认知、以及挑战常规假设或填补明确空白。

**层次一：确认已有认知。** 我们的实验结果与以下已有发现一致：（i）Krishnapriyan 等[8] 观察到 PINN 的失效与 PDE 参数存在规律性关系——我们在伯格斯中也观察到类似现象，并在更大的参数空间（二维扫描）中确认了这一规律；（ii）Wang 等[10] 证明了 PINN 中不同损失分量的收敛速率不一致——我们的消融分析在宏观层面确认了这一点，即去掉训练稳定性维度对不同系统的排序一致性有不同程度的影响；（iii）Rathore 等[9] 指出的多目标优化的刚度不平衡——我们在伯格斯中观察到的训练稳定性与误差的近乎正交（$R^2=0.057$）为这一微观机制提供了一种统计表现。

**层次二：延伸已有认知。** 我们的工作在以下方面将已有认知向前推进了一步：

（1）从"PINN 有时会失败"推进到"PINN 在二维观测退化空间中具有不同形态的失效边界"。Krishnapriyan 等[8] 展示了特定 PDE 参数下的成功/失败模式；本文将这一观察系统化为二维全因子扫描，并在三个系统中定量比较了边界的形状（窄规则 → 中等宽度 → 宽概率带）。

（2）从"训练稳定性是一个观察指标"推进到"训练稳定性在某些 PDE 中提供了与误差近乎正交的独立信息"。$R^2=0.057$ 表明在伯格斯中，即使误差很小，也不能排除训练不稳定的可能——这是使用单一误差指标进行可靠性判断时的一个系统性盲区。

（3）从"PDE 参数影响可靠性"推进到"PDE 类型比参数更根本地决定边界形态"。参数变化（如黏性系数、反应率）调节的是一个 PDE 类型内部的表现；PDE 类型之间的切换（如从线性耦合流切换到非线性对流-扩散）对应的是边界形态的质的改变——这一点在之前的研究中未被明确讨论。

**层次三：挑战常规假设或填补明确空白。** 以下是本文在实验证据支持下提出的、与 PINN 领域的某些常规认知不符或此前无人系统研究过的发现。

（3a）**多种子分析揭示的"概率边界"假说。** 当前 PINN 文献中，绝大多数实验结果以单一随机种子的形式报告——学界默认一个种子足以代表该配置的表现。我们的 30-40 种子高密度复现实验表明，在伯格斯这样的复杂系统中，即使是最"安全"的观测条件（$N_{\\mathrm{obs}}=128,\\sigma=0$），10% 的种子也会跨过质量阈值。而威尔逊区间显示，单个种子的 95% 置信区间宽度可达 0.26（10 种子时）——仅凭单次运行无法可靠区分"这个配置可能不行"和"这个配置确实不行"。本文在三级扫描设计中引入了概率边界概念（粗扫描定位 → 精化扫描细化 → 概率扫描估计威尔逊置信区间），为 PINN 实验的可复现性提供了一个可操作的统计框架。在 arXiv 检索中，"multi-seed + PINN + reliability"和"Wilson confidence + PINN"均无任何匹配结果，表明这一方法在此领域确属首次应用。

（3b）**单一误差与多维框架的根本分歧。** 四维 $R$ 与单一相对误差在前三分之一最差格点上的雅卡尔重合度为 0.000——两组识别出的"最危险工况"完全没有交集。这不仅意味着两者不同——它意味着仅用误差来排序风险，在伯格斯、费希尔和斯托克斯三个系统中都会漏掉四维框架识别出的关键危险信号。考虑到目前 PINN 文献中相对 $L_2$ 误差几乎是唯一的标准成功指标[1,2,17]，这一发现对"单指标足以衡量 PINN 可靠性"这一默认假设提出了实质性的挑战。

（3c）**校准稳定性的反直觉悖论。** 直觉上，简单系统（如斯托克斯）的评估框架应该比复杂系统（如伯格斯）更稳定——因为解更确定、训练更可复现。但我们的 27 组校准配置实验给出了相反的结果：伯格斯在全部 27 组下保持角色一致，而斯托克斯仅在 18 组下保持。反转的原因是：伯格斯的多维退化造成的维度间差距足够大，使得校准参数的变化不能翻转排序；而斯托克斯的退化路径高度集中，四个维度的得分几乎同步移动，微小的校准变化即可改变谁是"最低分的那一个"。这一发现对"简单系统 → 稳定诊断"的直觉提出了修正：稳定诊断取决于退化结构的多维性，而非系统的单纯复杂度。

（3d）**二维全因子扫描作为可靠性研究方法。** 当前 PINN 文献对观测稀疏度和噪声强度的处理通常是逐点测试——选择一个感兴趣的条件，在该条件下比较不同方法的表现。本文设计了"粗扫描 → 精化扫描 → 概率扫描 → 高密度探针"的四层次实验协议，将可靠性分析从"点测试"升级为"面扫描"，使得边界的位置、形态和统计宽度可以在统一的框架内进行跨系统比较。在 arXiv 检索中，"factorial + observation + noise + matrix + scan + PINN"无任何匹配结果——二维全因子可靠性扫描在此领域是新的实验范式。

（3e）**损失景观理论的经验验证。** Rathore 等[9] 的损失景观分析、Wang 等[10] 的 NTK 谱分析、以及 Krishnapriyan 等[8] 的 PDE 参数分析，分别在微观理论层面提出了 PINN 失效的可能机制。本文的宏观实验——消融分析的三系统谱系、$R^2=0.057$ 的信息独立性、临界带置换检验——为这些理论提供了跨系统、跨条件、多种子层面的经验证据。特别是，消融分析中伯格斯去训练稳定性维度降幅最大（0.033）而斯托克斯降幅可忽略（0.021），为 Rathore 等的"刚度不平衡在不同 PDE 中程度不同"这一推测提供了直接的定量支持。

（3f）**临界带内部异质性的统计证据。** 已有研究将"临界状态"视为一个过渡区间，但未进一步区分内部的不同类型。本文通过置换检验（$p\\approx 0.056$）和效应量（$d=0.93$）表明，伯格斯的临界带内部至少包含两种统计上可区分的退化模式——临界过渡型和种子敏感型。这意味着，"伯格斯方程在观测退化条件下表现不稳定"这一笼统的表述，在当前实验精度下应当替换为更精确的"伯格斯方程在观测退化条件下表现出两种不稳定性，分别对应不同的退化机制"。
