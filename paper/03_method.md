# 3 方法

## 3.1 问题定义

设偏微分方程定义在域Ω⊂ℝ^d上（对于时间依赖问题，域为Ω×[0,T]），待解函数为u*(x)。PDE的一般形式为

    N[u*] = f,  x ∈ Ω        (1)

初始条件和边界条件分别为

    u*(x,0) = g(x),  x ∈ Ω   (2)
    B[u*] = h(x),  x ∈ ∂Ω    (3)

其中N[·]为偏微分算子，B[·]为边界条件算子，f、g、h为已知函数。对于本文涉及的稳态问题（泊松方程、斯托克斯流、Allen-Cahn方程），式(2)不适用；对于瞬态问题（Fisher-KPP、Burgers、热方程、KdV、NLS、波方程），式(1)-(3)均适用。

观测数据为N_obs个离散点上的带噪测量值：

    {(x_i, y_i = u*(x_i) + ε_i)},  i = 1, ..., N_obs    (4)

其中ε_i为观测噪声，服从零均值高斯分布，标准差按各输出变量真值的标准差独立缩放：

    ε_i ~ N(0, σ² · diag(std(u₁*), ..., std(uₖ*)))    (5)

这里k为输出维度（标量问题k=1，斯托克斯流k=3）。N_obs控制观测稀疏度，σ控制噪声强度。本文的核心实验变量是(N_obs, σ)对，固定所有其他因素，仅改变这两个外部条件观察PINN预测状态的变化。

## 3.2 训练方法

PINN用一个全连接神经网络u_θ(x)逼近u*(x)，通过最小化组合损失函数进行训练。总损失函数定义为

    L(θ) = ω_data · L_data(θ) + ω_phys · L_phys(θ) + ω_bc · L_bc(θ)    (6)

各项的具体形式如下。数据损失度量预测解在观测点上的拟合误差：

    L_data(θ) = (1/N_obs) Σᵢ ‖u_θ(xᵢ) - yᵢ‖²    (7)

物理损失度量预测解对PDE控制方程的满足程度：

    L_phys(θ) = (1/N_col) Σⱼ ‖N[u_θ(xⱼ)] - f(xⱼ)‖²    (8)

其中{xⱼ}为域内随机采样的配点，N_col为配点数量。边界损失度量预测解对边界条件和初始条件的满足程度：

    L_bc(θ) = (1/N_bc) Σₖ ‖B[u_θ(xₖ)] - h(xₖ)‖² + (1/N_ic) Σₘ ‖u_θ(xₘ,0) - g(xₘ)‖²    (9)

其中{xₖ}为空间边界∂Ω上的采样点，{xₘ,0}为初始时刻t=0上的采样点。对于稳态问题（泊松、斯托克斯、Allen-Cahn），式(9)右侧第二项不适用，边界损失仅包含空间边界条件残差。对于瞬态问题，边界点集由空间边界点和初始时刻点两部分组成，两者的残差合并计算。

损失权重取ω_data=10、ω_phys=1、ω_bc=10，意味着数据拟合和边界满足的权重是物理约束的10倍。这一选择在所有PDE系统的clean baseline实验中均能提供稳定的收敛。

本文保持上述训练方法不做任何改动——未采用自适应采样（如残差自适应重采样RAR），未引入自适应损失权重（如基于不确定性的权重调整），也未改变网络的参数化方式。这一约束是刻意为之：只有固定训练算法，才能在后续跨方程比较中将边界形态差异归因于PDE本身的性质，而非归因于训练策略的不同选择。

网络结构与训练配置如下。网络采用3个隐藏层、每层64个神经元的全连接结构（记为3×64），输入维度对应PDE的空间坐标数（泊松、斯托克斯、Allen-Cahn为2维；Fisher-KPP、Burgers、热方程、KdV、NLS、波方程为2+1=3维），输出维度对应PDE的未知量个数（标量问题为1，斯托克斯流为3）。各隐藏层之间采取全连接策略，激活函数选取tanh函数。网络权重和偏置采用Xavier初始化，优化器为Adam，初始学习率1e-3，未使用学习率衰减。训练轮数500，每轮使用全部配点和边界点进行一次前向-反向传播。配点数量N_col=2048，边界点数量N_bc=256（对于瞬态问题，其中约一半为初始时刻点）。观测点从评估网格中随机采样，评估在独立的51×51均匀网格上进行。观测点、配点和边界点的采样均由随机种子控制，确保实验可复现。
