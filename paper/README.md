## 叙事逻辑线

```
§1 问题：PINN 在稀疏/噪声下何时可信？
§2 定位：已有工作做了什么，本文填补什么空白
§3 方法：四维可靠性框架怎么定义
§4 设计：实验怎么做（两个协议 × 十个 PDE）
§5 发现：三种退化原型（现象层）
§6 解释：四因素退化机制（机理层）
§7 补充：单一误差不够（诊断层）
§8 讨论：适用边界 + 未来方向
§9 结论
```

## 每节的独立职责

- **§1** 只说"问题是什么"和"本文做了什么"，不说"本文的创新点是"
- **§2** 用对比表定位，不用长段落罗列
- **§3** 定义框架，不做实验论证
- **§4** 描述实验设计，不展示结果
- **§5** 展示现象，每个子节一个原型，不做机理解释
- **§6** 解释机理，每个子节一个因素，用控制对照实验证明
- **§7** 说明单一误差的局限，用统计数据支撑
- **§8** 讨论框架的适用边界和未来方向
- **§9** 三句话总结
